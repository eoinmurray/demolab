# HOUSESTYLE

Write for reading, not for the build system. Lead with the point, use descriptive headings, define
specialised terms, and prefer direct prose. Use native Typst maths and tables. Use SVG for diagrams
and plots when practical, and provide alt text for meaningful images. Captions should explain what
the reader should notice rather than repeat the title. Keep presentation-specific overrides in
`HOUSESTYLE.local.md`; demolab does not enforce a house style.
